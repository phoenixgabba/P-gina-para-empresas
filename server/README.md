# FORMA API — foundation, not deployed
Node 22, Express, PostgreSQL 16. Copy .env.example to .env and configure DATABASE_URL (use db as host in Compose), POSTGRES_PASSWORD, PUBLIC_ORIGIN, optional Stripe test keys and SMTP. Never commit secrets. Run docker compose build; docker compose run --rm api node src/migrate.mjs; bootstrap owner with OWNER_EMAIL, OWNER_PASSWORD, STUDIO_NAME injected as environment, then docker compose up -d. Use a TLS reverse proxy; proxy /api to 127.0.0.1:8080 and serve the public frontend on the same origin. API is not connected to existing localStorage production demo. Endpoints: login/logout/me, clients, projects, quotes, accept, documents, checkout, Stripe webhook. Acceptance is an audit record, not a qualified electronic signature. Uploads validate basic signatures, not malware scanning. SMTP outbox retries up to five times, at-least-once. Payments require test-mode verification and webhook setup. Not implemented: secure invitation/reset, public anonymous brief, server rental inventory, full operational modules, file scanning, qualified signing provider, backup/restore and full frontend integration. Do not deploy for real customers before completion and integration testing.
